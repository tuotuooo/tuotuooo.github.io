# AETHER FRONTIER — 赛博机械风独立站点

一个纯静态的**赛博 / 机械档案风格**单页站点 Demo。复刻了沉浸式科技官网的设计语言（暗色底、几何线条、中英双语层级、卡片网格、整页翻页、HUD 角标、故障特效），但**全部使用原创占位素材，不含任何第三方 IP / 美术资产**。

> 虚构品牌：**AETHER FRONTIER / 以太边境**；干员为 K-01~K-06 代号占位。

---

## 技术栈

- 纯 **HTML + CSS + 原生 JavaScript**，**零依赖、零构建**。
- 无框架、无打包工具，直接丢到任意静态服务器即可运行。

## 目录结构

```
ark-style-site/
├── index.html        主站（正式站点）
├── virus-demo.html   备用 Demo：终端打字机 + 卡机收尾翻页转场
├── css/
│   └── style.css     全部视觉与动画样式
└── js/
    └── main.js       交互逻辑（翻页、动效触发、Loader、数字滚动等）
```

## 已实现的效果

### 主站（index.html）
| 模块 | 效果 |
|---|---|
| **首屏 Loader** | 机械转轮（双环反向旋转 + 虚线齿轮 + 中心 ◈ 脉冲）+ 进度条 0→100% |
| **整页翻页** | 桌面滑一下 = 翻一整页；滚轮 / 方向键 / PageUp·Down / Home·End / 点击右侧指示器均可翻页；翻页期间锁定防连翻；窄屏 / 触屏自动退回原生滚动 |
| **章节标题** | 进入时 RGB 双色错位 + 切片抖动故障（`glitchIn`）；悬停再触发一次短故障；标题头部 `clip-path` 扫描揭示 |
| **进入 / 退出特效** | 每屏进入时元素机械装配（标题扫描揭示、卡片纵向弹开错峰、列表滑入），退出时反向收起 |
| **HUD 角标** | 每屏四角机械括号 + 顶部刻度线，进入时淡入 |
| **Hero 雷达** | 背景中央缓慢旋转的雷达环（同心环 + 十字刻度 + 橙色扫描扇区） |
| **干员卡翻面** | 鼠标悬停 3D 翻转，露出背面能力简介（代号 / 定位 / STATUS 标签） |
| **数字滚动** | 关于页统计数字进入时从 0 机械滚动到目标值 |
| **全局扫描线** | 全屏极淡扫描纹理，机械屏质感 |
| **右侧翻页指示** | 固定竖排线条（HOME/NEWS/OPS/MOD/TIME/ABOUT），当前页高亮，点击跳页 |

### 备用 Demo（virus-demo.html）
- 翻页转场 = 终端打字机日志 + 进度条 + 卡机收尾（无抖动、无代码雨）。
- 因观感偏"重"，未整合进主站，仅作效果备用，随时可再接入。

## 本地预览

项目是纯静态文件，用任意本地静态服务器打开即可（端口随意）：

```bash
cd ark-style-site
python3 -m http.server 4100 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:4100/   （Demo: http://127.0.0.1:4100/virus-demo.html）
```

> 首屏 Loader 只在**整页刷新**时触发；翻页效果用滚轮 / 方向键体验最明显。

## 可定制方向

- 主色：当前暖金橙 `#f5a623` + 冷青 `#56ccf2`，可在 `style.css` 顶部变量区调整。
- 章节标题故障强度 / 时长（`glitchIn` 关键帧）。
- 翻页是否加回过渡（扫描线 / 病毒代码转场，二者代码均已保留可回滚）。
- 替换为真实内容（品牌名、公告、干员资料）。
- 增加子页面（新闻详情、干员详情）。
